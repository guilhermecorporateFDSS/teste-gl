# Fotografias reais

Adicione os arquivos WebP/AVIF nesta pasta e preencha o objeto `image` correspondente em `js/content.js`.

Exemplo: `{src:'assets/images/interior.webp', avif:'assets/images/interior.avif', srcset:'assets/images/interior-640.webp 640w, assets/images/interior.webp 1200w', alt:'Descrição objetiva da fotografia real', width:1200, height:900}`.

Hero: proporção aproximada 1:1; serviço: 4:3; comparador: duas fotos do mesmo enquadramento; resultados: 4:3; equipe: 1:1. Os contêineres já adaptam os cortes no celular.

O comparador continua identificado como ilustração até que seu texto seja atualizado após inclusão de fotos reais. Não usar imagens de terceiros como prova de resultado da empresa.
